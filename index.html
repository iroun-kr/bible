절과 절 사이 쉬는 시간

쉼표나 문장이 끝나는 곳에서도 잠깐 쉬어 읽습니다.

더 부드러운 목소리로 듣는 방법
  1. 아이폰: 설정 → 손쉬운 사용 → 읽기 및 말하기 → 음성 → 한국어 → 유나(고품질) 또는 프리미엄 음성 내려받기
  2. 갤럭시: 설정 → 일반 → 텍스트 음성 변환 → 기본 엔진에서 삼성 TTS 또는 Google TTS 선택 → 한국어 음성 데이터 내려받기
  3. 내려받은 뒤 이 앱을 다시 열고 위 목소리에서 새 음성을 고르세요.
